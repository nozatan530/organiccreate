# 合成マップの配置バランス・カメラワーク改善計画書
（Map Balance & Visual Hierarchy Improvement Plan）

## 1. 課題認識（現状の課題）
本アプリ（有機クラフト工房）は、第1章（炭化水素・20物質）、第2章（官能基・14物質）、第3章（芳香族・15物質）、第4章（高分子・23物質）と章が進むごとに、物質数・合成ルートの分岐・反応の種類が大幅に拡大しています。

ユーザーからのフィードバック：
> 「内容はいいけど、マップのバランスがどうしても崩れちゃいますね。改善するポイントとして記録しておいてください」

---

## 2. 根本原因の分析（Root Cause Analysis）

### (1) 動的 `targetViewBox` の急激なカメラ変動
- **現象**: 探索初期（発見ノードが1〜2個）のときは局所的に拡大（ズームイン）され、新たなノードが遠隔地に現れた瞬間にカメラが急激にパン・ズームアウトする。
- **原因**: `targetViewBox(shown)` が「発見済みのノード（`shown`）」の座標バウンディングボックスのみから毎フレーム再計算されているため、ノードの出現位置によって中心点（`cx, cy`）や拡縮率が大きく跳ねてしまい、空間の安定感が損なわれる。

### (2) 手動座標配置（2D平面）と反応ネットワークの多次元性の乖離
- **現象**: 一部の領域（例：第4章のビニロン系列や第1章のエチレン周辺）にノードが密集し、他の領域（無機試薬や独立した合成ルート）との余白バランスが不均一になる。
- **原因**: 化学反応は「直鎖的な変化（A→B→C）」、「合流（A+B→C）」、「分岐（A→B+C）」、「重合（n A→高分子）」などトポロジーが多様であり、固定の静的2D座標（`POS1`〜`POS4`）だけではエッジの交差やノードの重複を完全に吸収しきれない。

### (3) ノード幅の可変性による間隔の破綻
- **現象**: 「メタン」「PVA」のような短い名称（幅約78px）と、「1,1,2,2-テトラブロモエタン」「ポリエチレンテレフタラート」のような長大な名称（幅約180px超）が混在し、横方向の間隔（マージン）が局所的に詰まる・重なる。

### (4) 画面アスペクト比（PC/タブレット/モバイル）との不整合
- **現象**: マップSVGの表示領域はCSSのグリッド（`minmax(320px, 1fr)`）に依存しており、固定アスペクト比（1.6）と画面幅の組み合わせによって上下または左右に不自然な余白・見切れが生じる。

## 3. 改善施策ロードマップ（Phase別アクションプラン）

### 【Phase 1: 即時・短期施策（カメラと境界の安定化）】
1. **最小ビューポートの拡大とスムーズクランプ**:
   - `targetViewBox` の最小表示幅・高さを引き上げ、極端な局所ズームを防止。
   - 画面がマップ全体（`0, 0, 980, 740`）を自然に俯瞰できるよう、常に章の主要アンカーポイントを含めた緩やかなカメラワークを実現。
2. **座標オーバーフロー・負値座標の是正**:
   - `viewBox` の `x < 0` や `y < 0` への飛び出しを防止し、常に有効キャンバス内に収まるようクランプ処理を厳格化。

### 【Phase 2: 中期施策（セクター別表示・ミニマップ・自由ナビゲーション）】
1. **セクター・タブ切り替え型ビュー（大マップ分割）**:
   - 特に第4章（高分子・23物質）のような巨大マップにおいて、画面上部またはマップ内に**セクター切り替えチップ**（例：「🧵 合成繊維」「🚗 合成樹脂・ゴム」「🧬 天然高分子・生体」）を設置。
   - タブ選択により該当セクターへカメラがスムーズにフォーカス移動する仕組みを導入。
2. **ユーザー主導のパン＆ピンチズーム（インタラクティブ操作）**:
   - 自動カメラ任せにせず、マウスドラッグによる自由スクロール、ホイール/ピンチイン・アウトによる自由ズームをサポート。
   - 「全体を表示」「現在地へ戻る」ボタンをマップ右下に常設。
3. **ミニマップ（全体レーダービュー）の導入**:
   - マップ隅に全体構造のサムネイルを表示し、自分がどの領域を探求しているかを直感的に把握可能にする。

### 【Phase 3: 発展・根本施策（レイアウトアルゴリズムの自動化）】
1. **階層型自動配置アルゴリズム（Sugiyama Method / DAGレイアウト）**:
   - 原料（Layer 0）→ 中間体（Layer 1〜3）→ 最終高分子・医薬品（Layer 4〜5）の階層（ランク）構造を自動計算し、エッジ交差を最小化した上で均等なノード間隔を自動算出する。
2. **ノードサイズの規格化（バッジデザインの統一）**:
   - ノードの標準幅を3段階（S: 84px, M: 120px, L: 150px）に規格化。長大な化合物名はフォントサイズ縮小や適切な2行折り返しを適用し、隣接ノードへの干渉を根絶する。
