## 1. プロジェクトの目的

- 高校化学「有機化合物」（学習指導要領 化学(4)ア(ア)）の反応を、**ポーションクラフト型のゲーム**で探索しながら学べるWebアプリ。
- 原料を調達して反応させ、新しい物質を作ると、次の原料や道が解放されていく。
- 主な使い方は**自習用**。対象は高校生と、化学を学び直したい大人の両方。
- 作者は現役の高校理科教員（物理・探究担当、教育DX担当）。将来は勤務校の校内ポータルでの公開も視野に入れている。

## 2. 現在の到達点（v3）

### 2-1. 技術構成
- **HTML 1ファイル**（CSS・JSすべて内包）。フレームワークは使わず、素のJavaScriptで書いている。
- 外部読み込みは2つだけ。
  - Google Fonts：Dela Gothic One（見出し）、Zen Kaku Gothic New（本文）、IBM Plex Mono（化学式・数値）
  - `smiles-drawer@2.1.7`（jsDelivr）：SMILES記法から構造式をSVGで描画する。水素も表示する設定（`explicitHydrogens:true`）。読み込めないときは化学式の文字表示に切り替わる。
- 進み具合は `localStorage`（キー：`organic-craft-ch1-v2`）に保存する。読み書きはすべて try/catch で囲んである。
- ライトモードとダークモードの両方に対応。色はすべて `:root` のCSS変数で管理している。

### 2-2. 画面構成
| 場所 | 中身 |
|---|---|
| ヘッダー | タイトル、ランク（XPバー）、ひらめき★の数、「設定」（効果音・リセット） |
| 依頼バー | いまの依頼を1件だけ表示。「ヒント」「納品する」ボタン |
| 合成マップ（中央） | 霧の中から、発見済みの物質と「？？？」（作れそうな物質）が現れる。たどり着いた範囲に合わせて自動で拡大する |
| サイドパネル | 「調べる」（選んだ物質の手がかり）と「反応台」（フラスコA・B、温度・光・触媒、反応の種類の予想）を切り替える |
| 下部タブ | 物質図鑑／称号／実験ノート |
| ダイアログ | 物質の詳細（構造式・解説・使い道・作り方）、発見カード（NEW!演出） |

### 2-3. ゲームの仕組み
- **反応判定**：フラスコA・Bの組み合わせと、条件（温度・光・触媒）が `RULES` と一致すれば成功。
  - 組み合わせは合っているが条件が違う場合：「おしい！」と、理由つきのメッセージを出す（例：暗いと置換しない、170℃超で炭化）。
  - アルカンと臭素水のように、反応しないこと自体が学びになる組み合わせには、専用の説明を出す。
- **合成マップ**：手持ちの物質だけで作れる物質を「？？？」として表示する。まだ試していない別ルートは点線で示す。
- **次の一歩**：いまの依頼の目標から逆算し、最短ルートの最初の「？」をオレンジで点滅させる（`nextStep()`）。
- **手がかり**：「？」を押すと出発点は無料で見られる。相手の物質と条件は、ひらめき★を1つずつ使うと見られる。
- **報酬**：新物質の発見で「10＋レア度×10」XP、新しい反応で10XP。予想的中で★1、依頼の達成で50XPと★2、称号の獲得で★1。
- **レア度**：原料から何段目の物質か（1〜5）。`DEPTH` で自動計算する。
- **ランク**：見習い → 助手（150）→ 研究員（400）→ 主任研究員（750）→ 合成マスター（1150）。
- **依頼**：6件。達成するたびに原料の調達先や触媒が解放される。
  1. クロロホルム → 採石場（カーバイド）が開く
  2. 酸素アセチレン炎 → サトウキビ畑と薬品問屋が開く
  3. エチレン → 製油所（ナフサ）が開く
  4. 塩化ビニル → 重合触媒が使えるようになる
  5. ポリエチレン
  6. ベンゼン → 第1章クリア
- **称号**：9種類（例：「光の使い手」「温度の職人」「二つの道」）。
- **効果音**：Web Audio APIで鳴らす。設定でオフにできる。

### 2-4. コード内の主なデータ（`<script>` の上のほう）
| 名前 | 役割 |
|---|---|
| `S` | 物質の辞書。名前、化学式、分類 `cls`、SMILES `smi`、解説 `note`、使い道 `use` |
| `RULES` | 反応の定義。`in`（反応物）、`cat`（触媒）、`light`、`t`（温度範囲）、`out`（生成物）、`give`（副産物）、`types`（反応の種類）、`eq`（反応式）、`text`（解説）、`lowMsg` / `highMsg` / `catMsg`（失敗時のメッセージ） |
| `COMB` | 燃焼反応。`RULES` に自動で追加される |
| `SOURCES` / `CATS` | 原料の調達先と触媒。どの依頼で解放されるかも持つ |
| `QUESTS` / `ACH` / `RANKS` | 依頼、称号、ランク |
| `POS` / `MAPNAME` / `REGIONS` / `RAWSRC` | マップ上の座標（980×740の座標系）、マップでの短い名前、地域名、原料ノード |
| `DEX1` / `DEXX` | 図鑑の並び（第1章の20種／ほかの章の先取り・副産物6種） |

描画関数は `renderMap` / `renderLook` / `renderBench` / `renderQuest` / `renderTabs` で、`renderAll()` からまとめて呼ぶ。

## 3. 守るべきルール

### 化学の正確さ（最優先）
- 反応・条件・生成物は、高校化学の教科書の範囲と記述に合わせる。発展内容（マルコフニコフ則など）には「発展」と明記する。
- 反応式は係数まで正しく書く。構造式のSMILESは、水素を明示する形 `[H]C([H])...` で書く。
- 危険な物質（水銀化合物、四塩化炭素など）は、毒性や規制について解説に一言入れる。
- 新しい反応を追加したら、根拠（教科書のどの記述か）を作者に確認してもらう。

### ゲームデザイン
- 失敗したときは、必ず「なぜうまくいかなかったか」がわかるメッセージを返す。単に「失敗」とだけ出さない。
- 「どこから作るか」をマップで示すことをゲームの中心に据える。行き詰まらないように、「次の一歩」と依頼のヒントは必ず用意する。
- 答えをすぐ見せない。ひらめき★を使って段階的に開示する仕組みを保つ。

### UI（v3でゴチャゴチャを整理した経緯があるため、特に注意）
- 常に表示する情報を増やさない。新しい機能はタブやダイアログ、サイドパネルの切り替えに収める。
- マップ上の文字（反応条件のラベルなど）は、選択中の物質の周りにだけ出す。
- スマートフォン幅（約400px）でも操作できるようにする。マップは横にスクロールできる。
- 色は既存のCSS変数（分類色 `--c-alkane` など）を使い、ダークモードでも読めることを確認する。

### 実装
- 1ファイル構成を維持する（校内ポータルやアーティファクトにそのまま置けるように）。
- 外部スクリプトは jsDelivr / cdnjs からのみ、バージョンを固定して読み込む。
- データ構造を変えるときは、`localStorage` のキーの末尾の番号を上げる（古いセーブデータとの衝突を防ぐため）。
- `alert()` / `confirm()` は使わない（埋め込み先で動かないことがある）。確認はページ内で2段階押しにする。

## 4. 既知の課題・改善候補
1. 化学を履修していない人には難しい。→「やさしいモード」が必要（フェーズ1）。
2. 初回のチュートリアルがない。最初の1反応をガイド付きで体験させたい。
3. マップ後半（エチレン平原・石油の谷）でノードや線が密集している。座標の再調整が必要。
4. 「発見した反応」の総数がどこにも出ていない。図鑑タブに反応の一覧（反応図鑑）を加えたい。
5. 実際に遊んだ人の感想をまだ集めていない。★の手に入りやすさとヒントのバランスは、仮の値のまま。

## 5. 今後の方針（ロードマップ）

### フェーズ1：第1章の完成度を上げる
- **やさしいモード**（設定で切り替え）
  - 条件の手がかりが★なしで見られる。
  - 反応の種類の予想を2択にする。
  - 用語（付加・置換など）にポップアップで説明を出す。
- **チュートリアル**：メタンの塩素化を、手順を案内しながら1回体験させる。
- **反応図鑑**：発見した反応を「反応の種類」ごとに一覧できるようにする。
- マップ後半のレイアウトを調整する。

### フェーズ2：第2章「官能基の工房」
- 新しい仕組み：**鑑定**。正体不明の小瓶を、検出反応を組み合わせて特定するモード。
  - 使う検出反応：銀鏡反応、フェーリング液、ヨードホルム反応、ナトリウムとの反応、塩化鉄(III)
- 反応の候補
  - アルコールの酸化：エタノール → アセトアルデヒド → 酢酸、メタノール → ホルムアルデヒド → ギ酸、2-プロパノール → アセトン
  - エステル化とけん化：酢酸エチルなど
  - 油脂からセッケン
- 第1章で先取りしたエタノール・アセトアルデヒドなどを、そのまま引き継いで使う。

### フェーズ3：第3章「芳香族の塔」
- ベンゼンの置換反応（ハロゲン化・ニトロ化・スルホン化）
- クメン法（フェノールと一緒にアセトンも得られる、1回で2つ入手できる反応）
- サリチル酸から医薬品（アセチルサリチル酸・サリチル酸メチル）を作る依頼
- アニリン → ジアゾ化 → アゾ染料
  - ジアゾ化は5℃以下に保たないと分解する、という温度の仕掛けを入れる。
- **分離パズル**：エーテルと酸・塩基を使い、混合物を水層と有機層に振り分ける。

### フェーズ4：第4章「高分子の都」と全体の仕上げ
- 付加重合と縮合重合（ナイロン66、PETなど）。天然高分子にもふれる。
- 章をまたいだ「社会からの依頼」（薬・染料・素材の開発史）。化学(5)の内容とつなげる。
- 全章共通のマップにし、章ごとに地域を解放していく形にする。

### 公開・活用
- 校内ポータルでの公開、授業での導入の仕方（1回15〜20分で1依頼など）を検討する。
- 必要になったら、進み具合をクラウドに保存する仕組み（端末をまたいだ継続、先生の画面で進み具合を確認）を検討する。いまは端末内の保存だけ。
