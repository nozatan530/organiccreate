## 実装タスク

### フェーズ1：第1章の完成度を上げる

#### やさしいモード（設定で切り替え）
- [ ] 条件の手がかりを★なしで表示する
- [ ] 反応の種類の予想を2択にする
- [ ] 用語（付加・置換など）にポップアップ説明を追加する

#### チュートリアル
- [ ] メタンの塩素化を手順案内つきで1回体験させる

#### 反応図鑑
- [ ] 図鑑タブに「反応の種類」ごとの一覧ビューを追加する
- [ ] 発見した反応の総数を表示する

#### マップ調整
- [ ] エチレン平原・石油の谷のノード密集を解消する（座標再調整）

### 既知の課題

- [ ] 化学未履修者には難しい → やさしいモードで対応（上記）
- [ ] 初回のチュートリアルがない → チュートリアルで対応（上記）
- [ ] マップ後半でノードや線が密集している → 座標再調整で対応（上記）
- [ ] 発見した反応の総数がどこにも表示されていない → 反応図鑑で対応（上記）
- [ ] ★の手に入りやすさとヒントのバランスは仮の値のまま（実際のプレイテストが必要）
