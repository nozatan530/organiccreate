# 有機クラフト工房

## ひとことで

高校化学「有機化合物」の反応を、ポーションクラフト型のゲームで探索しながら学べる自習用Webアプリ。

## 利用者と場面

- **主な利用者**：高校生（自習）、化学を学び直したい大人
- **副次的利用者**：校内ポータルで使う高校教員
- **場面**：家庭学習・自習。将来は授業内導入（1回15〜20分で1依頼）も想定
- **端末**：Chromebook・iPad・スマートフォン（約400px幅）対応

## 体験の流れ（利用者目線）

1. マップで「？？？」のノードを見つけ、「何だろう？」と好奇心が湧く
2. 反応台にフラスコA・Bを選び、温度・光・触媒を設定して試す
3. 失敗したら「なぜ失敗したか」のメッセージで学ぶ
4. 成功すると新物質が発見され、XPと称号が手に入る
5. 依頼を達成するたびに採掘場・畑・触媒などが解放され、マップが広がる
6. 第1章の6依頼をすべて達成して「第1章クリア」

## 画面一覧

| 画面名 | 役割 |
|---|---|
| ヘッダー | タイトル・ランク（XPバー）・ひらめき★・設定 |
| 依頼バー | 現在の依頼（ヒント・納品ボタン） |
| 合成マップ | 発見済み物質と「？？？」を視覚化。自動ズーム |
| サイドパネル（調べる） | 選んだ物質の手がかり |
| サイドパネル（反応台） | フラスコ選択・条件設定・反応種類予想 |
| 下部タブ | 物質図鑑・称号・実験ノート |
| ダイアログ | 物質詳細（構造式・解説）・発見カード演出 |
